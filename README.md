# Fast Stairs Mod - Minecraft 1.17.1 Fabric

Um mod simples para Minecraft 1.17.1 (Fabric) que permite subir escadas 4 vezes mais rapidamente.

## Funcionalidades

- Aumenta a velocidade de subida em escadas em 4x
- Apenas afeta o movimento vertical enquanto sobe escadas
- Não altera nenhuma outra mecânica do jogo

## Requisitos

- Minecraft 1.17.1
- Fabric Loader >= 0.11.3
- Fabric API

## Instalação

1. Instale o [Fabric Loader](https://fabricmc.net/use/installer/)
2. Baixe e instale a [Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api)
3. Compile o mod executando `./gradlew build` (ou use um IDE como IntelliJ IDEA ou Eclipse)
4. Copie o arquivo `.jar` gerado em `build/libs/` para a pasta `mods` do seu Minecraft

## Como Usar

Basta subir em qualquer escada no jogo e você notará que está subindo 4 vezes mais rápido!
